In fixed account we can only deposit so this class can not be replaced with accouts class so this breaks liskov substitution so soltion is that we make two class depositableaccount and WithrawableAccout which extends depositableAccount. now fixed account will exted depositableAccount class only and rest will extend withdrwableAccount class so that they will have boht features as withdrawable class extends depositableAccount class also.
